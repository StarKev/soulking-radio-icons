## Utilisation dans un bot Discord

Ces icônes sont destinées à être utilisées comme miniature dans un embed :
```python
embed = discord.Embed(title="🎶 Lecture de la radio", description="lofi hip hop radio 📚")
embed.set_thumbnail(
    url="https://raw.githubusercontent.com/StarKev/soulking-radio-icons/main/radios/lofi_girl.png"
)
```
